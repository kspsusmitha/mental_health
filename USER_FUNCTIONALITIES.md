# User Functionalities Breakdown
## AI-Powered Mental Health & Wellness Support System

This document outlines all functionalities available to each user type in the system.

---

## 👤 USER MODULE FUNCTIONALITIES

### 1. AI Chatbot 🤖
**Functionality:**
- **24/7 Conversational Support**
  - Chat with AI-powered chatbot anytime
  - Natural Language Processing (NLP) for understanding user messages
  - Get instant mental health support and guidance
  
- **Mood Detection**
  - AI analyzes conversation to detect current emotional state
  - Identifies stress, anxiety, depression, etc.
  - Provides real-time emotion analysis
  
- **Coping Suggestions**
  - Receives personalized coping strategies based on detected mood
  - Gets immediate support and advice
  - Suggests activities to improve mental state
  
- **Therapist Recommendation**
  - AI recommends connecting with a therapist when needed
  - Suggests based on severity of emotional state
  - Provides guidance on when professional help is beneficial

**Access:** Available 24/7, no appointment needed

---

### 2. AI Mood Prediction 📊
**Functionality:**
- **Pattern Recognition**
  - Analyzes chat history and mood entries
  - Identifies recurring stress patterns
  - Predicts potential mood episodes
  
- **Stress Pattern Prediction**
  - Predicts when user might experience stress
  - Identifies triggers and patterns
  - Provides early warning system
  
- **Historical Analysis**
  - Reviews past mood data
  - Identifies trends over time
  - Shows mood cycles and patterns

**Access:** Based on user's historical data

## 🔐 ACCESS CONTROL SUMMARY

### User Module Access:
- ✅ Full access to all user features
- ❌ Cannot access therapist features
- ❌ Cannot access admin features
- ✅ Can view approved content only
- ✅ Can book appointments with verified therapists

### Therapist Module Access:
- ✅ Full access to therapist features
- ✅ Can view matched users
- ✅ Can access user emotion reports (for their clients)
- ❌ Cannot access admin features
- ❌ Cannot access other therapists' clients
- ✅ Can manage own appointments and sessions

### Admin Module Access:
- ✅ Full access to all admin features
- ✅ Can view all users and therapists
- ✅ Can approve/reject content
- ✅ Can moderate community posts
- ✅ Can verify therapists
- ✅ Can manage system settings
- ❌ Cannot access user/therapist personal data beyond management needs
